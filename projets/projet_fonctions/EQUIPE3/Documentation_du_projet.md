## Présentation de l'équipe et brève description du projet :

Ce projet a été produit par l'équipe 3 composée de Christian et Raymond. Il consista à écrire un programme permettant à l'utilisateur de gérer de : inscrire un élève, consulter les infos d'un élève, modifier les informations d'un élève, consulter les détails des frais et les statistiques générales.  

## Objectifs dun projet :

Le projet avait pour but de consolider les notions apprises aucours de la semaine notament les différents types de fonctions, les différents types d'arguments...
