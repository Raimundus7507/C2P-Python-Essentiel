# Documentation du Projet Nom_du_Projet

## 👥 Présentation de l'équipe et brève description du projet

Ce projet a été réalisé par l'équipe 3, composée de Christian et Stephanie.  
Il consiste à écrire un programme de jeu utilisant les boucles for et while.  
L’objectif est de permettre à l’utilisateur de jouer au jeu de devinette,dont deviner un nombre, effectuer des calculs,de deviner des lettres et simuler le lancer de DE, etc.

## 🎯 Objectifs du projet

Le projet a pour but de mettre en pratique les notions vues en cours, notamment :  

- Les boucles (while, for)  
- Les instructions de contrôle (break, continue, pass)  
- Les conditions (if, elif, else)  
- La gestion d’entrées utilisateur avec input() et les conversions de types
